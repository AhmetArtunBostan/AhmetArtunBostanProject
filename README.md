# Shopping App by Ahmet Artun Bostan

A modern React Native shopping application with a beautiful UI and smooth animations.

## 🚀 Features

- **Elegant Splash Screen**
  - Custom animations and transitions
  - Professional design elements
  - Welcome message

- **Product Management**
  - Browse products by categories
  - View product details
  - Filter Men's and Women's clothing

- **Shopping Cart**
  - Add/remove items
  - Adjust quantities
  - Real-time price updates
  - View total amount

- **Checkout Process**
  - Add delivery address
  - Select payment method
  - Order confirmation with animations
  - Success message with visual effects

## 🛠️ Built With

- React Native
- Expo
- React Navigation
- React Native Animations

## 📱 Screenshots

- Splash Screen: Professional welcome screen with animations
- Home Screen: Product categories and listings
- Cart: Shopping cart with quantity controls
- Checkout: Order placement and confirmation

## 🏃‍♂️ Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run the App**
   ```bash
   npx expo start
   ```

3. **Use Expo Go**
   - Scan QR code with Expo Go app
   - Or run on your preferred simulator
